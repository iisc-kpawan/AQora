# Data availability

The repository distributes software and benchmark questions, not observation
data. Air-quality observations and station metadata remain subject to their
upstream providers' access conditions and are configured separately for each
deployment.

The research described in the paper builds on Air Quality Arena. Users should
obtain eligible inputs from the cited upstream sources and comply with the
applicable provider licences and terms. No private server address, local path,
database, partition, station file, or ingestion checkpoint is included here.

Portable unit tests construct small synthetic values in memory and therefore do
not require access to the research corpus.

The authors' own ingested corpus and built lakehouse, used to produce the
results reported in the paper, currently reside only on the authors' server.
They are not distributed with this repository and will be made available for
public access after the paper's review period concludes.
