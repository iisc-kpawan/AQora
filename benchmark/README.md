# AQora benchmark

`aqa_eval_300_questions.csv` contains the complete questions-only benchmark
described in the paper. Its sole column is `question`; all development metadata,
answers, scoring guidance, and internal annotations have been removed.

`aqa_eval_10_representative_questions.csv` contains the 10 representative
questions (two per difficulty level, L1-L5) used for the quantitative
evaluation reported in Table 1 and listed in Table 2 of the paper. It is a
labeled subset kept separate from the 300-question benchmark so reviewers can
find the exact evaluated questions without searching the full set.
